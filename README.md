# PPTP Bridge для macOS

Ручное подключение по SSH и SMB к выбранным IPv4-адресам через существующий PPTP-сервер. Двойной щелчок по приложению включает туннель и подключает сетевой диск в Finder. Следующий запуск извлекает диск и выключает виртуальную машину.

## Установка

1. На Mac с Apple Silicon установите Homebrew в стандартный каталог `/opt/homebrew`. Для сборки и первого запуска нужны Apple Command Line Tools. Их можно установить командой `xcode-select --install`.
2. Скачайте DMG из [GitHub Releases](https://github.com/fkliuev/pptp-bridge-macos/releases). Для проверки скачанного файла выполните `shasum -a 256 PPTP-Bridge-1.0.0-arm64.dmg` и сравните результат с файлом SHA256SUMS в релизе.
3. Откройте образ и запустите **Install PPTP Bridge.pkg**. Для установки нужны права администратора. Сборка не нотарифицирована Apple. Если macOS блокирует доверенный пакет после попытки открытия, разрешение для него доступно в разделе «Системные настройки → Конфиденциальность и безопасность».
4. Откройте **PPTP Bridge** в «Программах». В Терминале мастер предложит ввести адрес PPTP-сервера, логин, адреса SSH и, по желанию, сервер SMB, имя общей папки и учётные данные. Адрес сервера SMB и имя папки вводятся отдельно. Пароли вводятся скрыто.
5. Дождитесь сообщения о готовности. Мастер установит QEMU через Homebrew, если он отсутствует, скачает образ Debian и настроит виртуальную машину. Один запрос sudo разрешает запуск GRE-транспорта для выбранного VPN-сервера. Для сборки 1.0.0 требуется macOS 13 или новее, доступ в интернет при настройке и несколько ГБ свободного места. Поддержка MPPE-128 нужна на стороне сервера, а сеть должна пропускать TCP 1723 и GRE.

## Использование

Откройте приложение либо выполните `/usr/local/bin/pptp-bridge on`. Для SSH используйте обычную команду `ssh пользователь@адрес` с одним из адресов профиля. Подключённая папка SMB отображается в Finder. Для выключения снова откройте приложение либо выполните `/usr/local/bin/pptp-bridge off`. Перед выключением закройте файлы на сетевом диске. Автозапуск отсутствует.

## Устройство

macOS обслуживает GRE, а Debian ARM64 в QEMU выполняет PPP и MPPE. Клиент создаёт в гостевой ОС маршруты /32 и блокирует выход к этим адресам через обычный шлюз при разрыве туннеля. SSH использует ProxyCommand для указанных узлов, SMB проходит через SSH-переадресацию на loopback. На хосте используются локальные TCP-порты 33582 и 14446. Одна установка рассчитана на один активный профиль.

Ключи клиента и гостевой ОС создаются при настройке. Пароли VPN и SMB хранятся в Связке ключей пользователя. Профиль и образ диска находятся в `~/Library/Application Support/PPTP Bridge`. Правило sudoers ограничивает запуск хешем исполняемого файла, UID и выбранным PPTP-сервером. После открытия GRE-сокета программа сбрасывает привилегии.

## Сборка

На Mac с Apple Silicon из корня репозитория выполните `./packaging/build.sh`. Образ и его контрольная сумма появятся в `dist/`. В `vendor/pptp` находятся исходники PPTP Client 1.10.0 с адаптацией для Darwin, обработкой закрытия соединения, повторного подключения и сброса привилегий. Лицензия — GNU GPL версии 2 или более поздней. Образ Debian скачивается с cloud.debian.org и проверяется по закреплённой сумме SHA-512.
